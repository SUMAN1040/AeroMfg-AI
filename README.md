# AeroMfg AI | AIoT Intelligence for Commercial Aircraft Manufacturing & Launch Operations

An enterprise-grade web application replicate of [AeroMfg AI](https://aeromfgai.com/) built **strictly using pure HTML5 and CSS3 — with zero JavaScript, zero frameworks, and zero external script dependencies**.

## Overview

AeroMfg AI delivers an integrated Artificial Intelligence of Things (AIoT) intelligence framework engineered for zero-failure commercial aircraft manufacturing, final assembly lines (FAL), orbital hardware lifecycle management, and launch vehicle ground operations.

## Architecture Highlights

* **100% Pure HTML5 & CSS3**: No `<script>` tags, no JavaScript libraries, and no inline JavaScript event listeners (`onclick`, `onchange`, etc.).
* **Pure CSS Modals (`:target`)**: Modals for Component Genealogy Dossiers, Plant Feasibility Assessments, and Technical Architecture Consultations are powered natively through CSS `:target` pseudo-classes with silky smooth backdrop blurs and exit links.
* **Pure CSS Layer & Simulation Controls (`:checked`)**: The Final Assembly Line (FAL) & Launch Integration Digital Twin features interactive layer toggling (All Layers, Workforce UWB, Calibrated GSE, ISO-5 Cleanroom, Launch Pad LC-39) and real-time hazard breach / smart torque verification simulations driven entirely by CSS sibling selectors and radio inputs.
* **Pure CSS Keyframe Animations**: Continuous SVG blueprint animations including technician UWB transit along assembly waypoints, rotating radar sweep beam, and pulsing status beacons.
* **Pure CSS Case Study Filters**: Interactive filtering across all 11 Problem-Solution-Result (PSR) aerospace deployment benchmarks (United States, Canada, Space & Launch Ops, Workforce Safety, GSE Tooling, Digital Thread).
* **Pure CSS API Documentation Tabs**: Bidirectional RESTful API & Telemetry Webhook code explorers with mTLS 1.3 data contracts and syntax styling.
* **Native Disclosure Widgets (`<details>` / `<summary>`)**: Inspectable cryptographic JSON payloads inside component genealogy dossiers without any JavaScript requirement.
* **Mobile Navigation Drawer**: Responsive slide-out navigation powered by pure CSS hidden checkbox input state toggling.

## Key Sections

1. **Top System Monitoring Bar**: Real-time Puget Sound FAL-04 and Cape Canaveral LC-39 mesh node status and standards indicators.
2. **Site Header & Mega Dropdowns**: Multi-column hover dropdown menus for Workforce Security, Asset Lifecycle, IoT Software, Sensing Hardware, and Launch Operations.
3. **Hero Command Section**: Dual focus on commercial aircraft manufacturing and orbital launch operations with live telemetry HUD card and metrics.
4. **FAL & Launch Digital Twin Simulator**: Animated CAD/SVG blueprint with live sensor feeds, cobot dynamic speed regulation, and simulated hazard geofences.
5. **Serialized Component Registry**: Tabular asset registry with 8 serialized aerospace assets and individual digital thread dossiers.
6. **Workforce Security Intelligence**: Personnel proximity analytics, secure perimeter access logic, and hazard compliance.
7. **Asset Lifecycle Intelligence**: Airframe hardware tracking, GSE tooling calibration gatekeeping, and predictive demand modeling.
8. **IoT Software for Aerospace**: Assembly WIP tracking, cryptographic digital thread genealogy, and automated QA traceability.
9. **Aerospace IoT Sensing Technologies**: Industrial UHF RFID nodes, precision BLE beacons, telemetry gateways, and environmental units.
10. **Space Operations Deployment Applications**: Satellite integration & AI&T, launch pad GSE logistics, TVAC environmental AI, and space supply chain.
11. **11 Verified PSR Case Studies**: 8 U.S. and 3 Canadian deployments formatted in Problem-Solution-Result layout with lessons learned.
12. **RESTful API Specifications**: Interactive tabbed code payloads for geofence webhooks, digital thread provenance queries, and launch pad streams.
13. **Aerospace Compliance Matrix**: AS9100 Rev D, FAA AC 21-43, NASA-STD-8739, DO-178C / DO-254 Level A, and prime contractors compatibility.
14. **ROI Estimator & Plant Feasibility**: Economic payback model and full modal assessment report.
15. **Technical Consultation Request**: Pure HTML5 form with full input validation and confirmation view.
